# NetSpeed · 应用网速

Swift 编写的 macOS 菜单栏小工具。菜单栏默认持续显示整机 Wi-Fi／以太网的上传、下载速率；点击查看网络地址与各应用／进程的流量明细。面板关闭时停止进程采样，菜单栏的轻量网卡统计继续更新。

## 运行

需要 macOS 13 或更高版本，以及 Swift 6.0 或更高版本的 Xcode Command Line Tools（命令行开发工具）。无第三方依赖。

```bash
bash scripts/build-app.sh
open dist/NetSpeed.app
```

生成的 `dist/NetSpeed.app` 可直接双击，也可手动拖到“应用程序”。这是本机临时签名构建，未做 Apple 公证。开发时可用 `swift run NetSpeed`，或在 Xcode 中打开 `Package.swift`。

打包 v1.1.0 安装映像：

```bash
bash scripts/build-dmg.sh
```

脚本读取 `Resources/Info.plist` 中的版本号，重新构建并生成 `dist/NetSpeed-v1.1.0-<架构>.dmg`。映像内包含应用和“应用程序”文件夹快捷方式，可拖入安装；使用当前 Mac 的架构构建，不是通用二进制。当前版本为 `1.1.0`，构建号为 `5`（新增网络地址信息、按需查询及菜单栏显示设置）。

## 使用

- 菜单栏默认上排显示 ↑ 上传，下排显示 ↓ 下载，约每秒更新；单位自动切换 KB/s、MB/s、GB/s，保留一位小数。舍入达到 1000 时切换下一级单位，不使用加号封顶；最高单位保留完整数值。首次采样和恢复时显示“—”，读取失败也显示“—”并自动重试，悬停可查看原因。
- 点击面板底部齿轮打开“菜单栏设置”，可选择“图标与网速”“仅网速”或“仅图标”；至少保留一个可点击入口。
- 网速样式支持独立隐藏 ↑／↓、使用简洁单位 K／M／G（省略 B/s）、保留 0／1／2 位小数，以及选择本机已安装字体。字号可在 7–12 pt 范围内以 0.5 pt 调整，默认 9 pt；更改即时生效并保存。过高的字形自动适配两行高度，图标与箭头大小不随字号改变。上排始终上传，下排始终下载；默认使用系统等宽数字。字体不可用时回退到系统字体，设置不改变应用列表的显示格式。
- 数字与单位之间始终保留一个空格。零位小数时按 `999 K`／`999 M` 或 `999 KB/s`／`999 MB/s` 的完整样例预留宽度；小数设置仅增加相应小数点与位数。上下两行的数字与单位作为整段文字右对齐，图标和箭头位置固定。
- 设置窗口提供示例预览，更改立即生效并自动保存，重启后保留；隐藏图标、箭头或缩短单位时，菜单栏占位随之收缩；“恢复默认”重置全部菜单栏样式。仅图标模式暂停网卡采样并保留样式，切回网速模式后约一秒恢复更新。
- 点击菜单栏展开面板：顶部显示网络信息，下方应用列表约一秒后显示进程速率，展开期间约每秒刷新。
- 网络信息显示在线 Wi-Fi／以太网的本机地址，以及分别查询的公网 IPv4／IPv6 和可用的出口地区旗帜；点击地址复制，刷新按钮重新查询。多本机地址可滚动，长 IPv6 自动换行。
- 默认下载降序；点击“上传”或“下载”切换排序，再次点击切换升降序。表头无箭头，当前排序列用蓝色和字重标记。
- 保留零流量进程，奇偶行交替底色，列表支持滚动。
- 应用列表按十进制显示 KB/s（千字节每秒）和 MB/s（兆字节每秒），保留两位小数。
- 点击面板外、再次点击图标或按 Esc 关闭，立即终止进程采样和地址请求；启用菜单栏网速时数字继续更新。重新展开丢弃旧的进程数据，重新取样。
- 底部“开机启动”开关控制当前用户登录 Mac 后自动启动，首次运行不会自动开启。建议先将应用放到“应用程序”文件夹再开启；出现“待批准”时点击前往系统设置允许。启动后按已保存的设置显示菜单栏，展开面板才开始进程采样。
- 休眠、用户会话离开时停止两种采样并关闭面板；恢复后菜单栏重新建立基准，不计算休眠期间的平均流量。底部“退出”按钮或 ⌘Q 退出程序。

界面参考紧凑的 macOS 状态小组件，采用浅灰底色、细描边圆角分组和蓝色标题，支持浅深色外观。列表单行展示，悬停可查看完整名称与 PID；底部左侧为“开机启动”开关，右侧为设置齿轮和“退出”按钮。设计取舍见 [界面设计说明](docs/interface-design.md)。

## 数据与生命周期

菜单栏通过 `sysctl NET_RT_IFLIST2` 读取在线 `en*` Wi-Fi／以太网接口的 64 位字节计数，逐接口按实际单调时间间隔求差后汇总。不启动子进程，不保存历史序列；排除回环、VPN 隧道、桥接和点对点接口，避免与物理出口重复累计。统计包含局域网流量和 VPN 的物理出口流量，不代表线路最大带宽。网卡新增、重建、计数重置时重新建立该接口基准。

应用列表使用系统 `/usr/bin/nettop -P -n -x -d -L 2 -s 1 -J bytes_in,bytes_out`。每轮跳过首次累计值，用第二帧约一秒内的流量增量近似每秒速率；不请求管理员权限，不安装后台服务。采样失败会清除旧数据、显示错误并提供重试，不将失败伪装为零速率。

沿用终端版本的**进程维度**，PID 是进程编号，不把浏览器等应用的辅助进程强行合并。仅显示 `nettop` 当前可见的联网进程，包括其中暂时空闲的进程，不是所有已安装应用。VPN（虚拟专用网络）、本地代理、系统服务和辅助进程会影响归属；列表不等同于物理网卡总流量。

公网地址通过 HTTPS 分别请求 `ipv4.icanhazip.com`、`ipv6.icanhazip.com`，再将查到的地址发送给 `ipwho.is` 查询国家／地区；地区失败仍显示地址。服务会看到请求的出口地址。代理／VPN 可能影响结果，两种地址族的出口也可能不同；“暂不可用”表示本次查询失败，不代表设备不支持该地址族。应用不在磁盘保存地址。

地址查询只在面板展开时执行，关闭立即取消；成功缓存五分钟、失败缓存三十秒。展开期间每五秒读取本机接口，发现地址或隧道变化后使公网缓存失效；仅代理配置或路由变化而接口地址不变时，需等待缓存过期或点击刷新。每次 HTTPS 请求资源超时八秒，响应上限 8 KiB；地址与地区依次查询，两个地址族并行执行。

- `NetSpeedCore`：解析、格式化、排序、网卡计数、网络地址和采样／查询生命周期。
- `NetSpeed`：AppKit 菜单栏／弹出面板、SwiftUI 网络信息与列表；面板事件控制进程采样和地址查询。
- 关闭面板时取消进程更新与地址任务并终止子进程；代次检查阻止旧采样或查询结果覆盖新面板。
- 首次点击才创建面板视图，关闭完成后释放视图控制器；排序选择在当前运行期间保留。进程图标只持有 16 pt 所需的 32×32 像素位图。
- 进程采样每轮有五秒超时；仅在面板展开时运行，后台读取管道。启用网速显示时，菜单栏独立以约一秒间隔读取轻量内核统计，数值不变时不重绘菜单栏。

## 验证

```bash
swift test
bash scripts/build-app.sh
bash scripts/check-panel-memory.sh 20
bash scripts/check-menu-bar.sh
# 可选：包含真实公网请求的面板生命周期检查
bash scripts/check-menu-bar.sh --network
bash scripts/render-previews.sh
```

人工检查：启动但不展开时菜单栏数字持续更新，且无此程序启动的 `nettop`；展开时有数据并可排序；关闭后 `nettop` 退出，菜单栏继续更新；快速反复开关不会显示旧样本。可用 `pgrep -P <NetSpeed 的 PID> nettop` 检查子进程。

菜单栏检查脚本会短暂创建一个独立菜单栏项目，验证真实网卡读取、设置切换与恢复、窗口释放，以及本进程内模拟的休眠／会话通知，并在 `.build/menu-bar-previews/` 输出真实菜单栏按钮的浅深色预览；不改变系统电源状态，结束时移除该菜单栏项目。加 `--network` 同时验证仅图标模式展开时的 nettop 和公网查询组合，以及关闭、快速重开、请求取消后的状态与视图释放；日志只输出地址数量和查询状态，不打印地址。

内存检查脚本使用固定 60 行示例数据离屏渲染，验证关闭后控制器释放、采样停止、重开保留排序及图标缩略图尺寸，并输出物理内存占用。它不打开窗口、不读取真实网络、不修改登录项；数值不等同于完整应用在真实桌面上的占用。

开机启动使用 macOS 13+ 的 `SMAppService.mainApp`，状态随系统登录项同步。命令行 `swift run` 不支持注册；移动或重新构建应用后，可能需要关闭并重新开启开关。自动化测试使用替身服务，不修改本机登录项；实际登录自启需在固定安装位置开启后注销并重新登录验证。
