# NetSpeed · 应用网速

Swift 编写的 macOS 菜单栏小工具。点击菜单栏网络图标查看各应用／进程的上传、下载速率；面板关闭时不采样、不刷新，也不在菜单栏显示实时数字。

## 运行

需要 macOS 13 或更高版本，以及 Swift 6.0 或更高版本的 Xcode Command Line Tools（命令行开发工具）。无第三方依赖。

```bash
bash scripts/build-app.sh
open dist/NetSpeed.app
```

生成的 `dist/NetSpeed.app` 可直接双击，也可手动拖到“应用程序”。这是本机临时签名构建，未做 Apple 公证。开发时可用 `swift run NetSpeed`，或在 Xcode 中打开 `Package.swift`。

## 使用

- 点击菜单栏网络图标展开，约一秒后显示速率，展开期间约每秒刷新。
- 默认下载降序；点击“上传”或“下载”切换排序，再次点击切换升降序。表头无箭头，当前排序列用蓝色和字重标记。
- 保留零流量进程，奇偶行交替底色，列表支持滚动。
- 按十进制显示 KB/s（千字节每秒）和 MB/s（兆字节每秒），保留两位小数。
- 点击面板外、再次点击图标或按 Esc 关闭，立即终止采样。重新展开丢弃旧数据，重新取样。
- 休眠、用户会话离开时关闭面板并停止采样。底部“退出”按钮或 ⌘Q 退出程序。

界面参考紧凑的 macOS 状态小组件，采用浅灰底色、细描边圆角分组和蓝色标题，支持浅深色外观。列表单行展示，悬停可查看完整名称与 PID；底部仅保留“关闭即暂停”和“退出”。设计取舍见 [界面设计说明](docs/interface-design.md)。

## 数据与生命周期

使用系统 `/usr/bin/nettop -P -n -x -d -L 2 -s 1 -J bytes_in,bytes_out`。每轮跳过首次累计值，用第二帧约一秒内的流量增量近似每秒速率；不请求管理员权限，不安装后台服务。采样失败会清除旧数据、显示错误并提供重试，不将失败伪装为零速率。

沿用终端版本的**进程维度**，PID 是进程编号，不把浏览器等应用的辅助进程强行合并。仅显示 `nettop` 当前可见的联网进程，包括其中暂时空闲的进程，不是所有已安装应用。VPN（虚拟专用网络）、本地代理、系统服务和辅助进程会影响归属；列表不等同于物理网卡总流量。

- `NetSpeedCore`：解析、格式化、排序、采样进程及启动／停止生命周期。
- `NetSpeed`：AppKit 菜单栏／弹出面板、SwiftUI 列表；由面板的显示和关闭事件控制采样。
- 关闭时取消更新任务并终止子进程；代次检查阻止旧采样结果覆盖新面板。
- 每轮有五秒超时；仅在面板展开时存在采样任务。后台读取管道，避免阻塞界面。

## 验证

```bash
swift test
bash scripts/build-app.sh
```

人工检查：启动但不展开时无此程序启动的 `nettop`；展开时有数据并可排序；关闭后 `nettop` 退出，等待几秒仍不会重启；快速反复开关不会显示旧样本。可用 `pgrep -P <NetSpeed 的 PID> nettop` 检查子进程。
