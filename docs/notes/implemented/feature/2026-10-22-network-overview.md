# Agent Note: Network overview and address lifecycle

Status: implemented

## Problem

面板需要同时回答整机当前上传／下载速度、近期变化及当前网络地址，并保留应用明细。直接相加进程流量可能重复统计代理链路；持续查询公网或保留隐藏面板的趋势会增加后台开销。

## Decision

本记录中的总览、趋势序列及面板触发网卡采样的决定已由[移除总览与趋势](2026-10-22-remove-network-summary.md)取代；以下保留原取舍，地址查询、缓存及取消规则仍有效。

原方案的整机总览复用菜单栏的物理网卡采样，通过每次采样回调记录时间序列；原有数值变化回调继续只负责菜单栏渲染。连续零速率仍推进时间，读取错误保存缺口而非伪造零。只在面板展开时保存最近一分钟、最多六十点，关闭立即清空。

网络面板模型拥有地址任务、内存缓存与可见性，视图仅呈现快照。公网两个地址族独立查询，地区为可选补充；读取本机接口时同时记录隧道地址作为缓存失效依据。刷新、关闭与网络变化取消任务并推进代次，迟到结果不能覆盖新面板。服务响应有大小和超时限制，并验证地址族及地区字段；提前结束读取也取消底层传输。具体查询端点和缓存时限由 README 的数据与生命周期章节维护。

原方案中面板打开本身成为网卡采样消费者，因此仅图标模式打开时也启动网卡采样，关闭后停止。这部分细化了[菜单栏显示设置](2026-10-22-menu-bar-preferences.md)的停止条件；其样式、持久化与窗口规则继续有效。

原方案界面沿用紧凑宽度，顶部使用共享纵轴的双向柱图，随后显示可复制的地址，再保留应用明细。多个本机地址在局部滚动，长 IPv6 在分组边界换行；复制使用原始字符串。历史仅覆盖本次展开期间，不制造关闭期间的数据。

## Alternatives considered

- 相加进程速率作为总网速：代理与辅助进程可能重复统计，无法代表物理网卡流量。
- 面板另起网卡定时器：与菜单栏重复采样并产生两个时间基准，复用采样更直接。
- 使用数值变化回调记录趋势：持续零速率时没有样本，时间轴会停止。
- 持续后台查询地址与记录趋势：没有面板消费者时仍消耗资源，与按需展示的目标不符。
- 查询失败即判断设备没有 IPv6：DNS、代理或服务故障都可能导致失败，因此仅显示暂不可用。

## Consequences

公网服务能看到请求出口，地区查询还会收到所查地址；代理可能影响查询结果。接口地址不变的路由或代理变化依赖缓存过期或手动刷新。地区失败不影响地址显示，但地址目前等地区查询结束后一起发布，最坏会等待两次请求时限。应用不持久化地址或历史；框架仍可能缓存网络连接和内存，释放面板不保证物理内存立即下降。

原验证覆盖长度／地址族校验、缓存、网络切换、快速关闭重开、迟到响应以及连续零值；移除总览后的验证范围见后续记录。无凭据离屏预览覆盖浅深色、多接口、长 IPv6 和查询失败，内存脚本验证反复开关后控制器释放。公网服务可用性依赖当前网络；这些结果不替代其他 macOS 版本和实际 VPN 切换的人工验证。
