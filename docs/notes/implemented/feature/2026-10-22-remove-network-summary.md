# Agent Note: Remove panel speed summary and history

Status: implemented

## Problem

用户不接受面板顶部整机上传／下载总览和趋势图的视觉效果，要求删除两者，同时保留已加入的 IP 信息。

## Decision

删除总览视图、历史样本及每次网卡采样回调，面板缩至 380 × 500 pt。菜单栏保持实时网速，主面板保留网络地址、应用列表及原有操作。

地址更新不再依赖网卡速率采样。网络面板模型仅在展开期间每五秒检查接口并处理缓存，关闭取消轮询与查询；取消及代次检查继续拒绝迟到结果。仅图标模式无论面板是否打开都暂停网卡速率采样。

本决定部分取代[网络总览与地址](2026-10-22-network-overview.md)的总览、历史序列和网卡采样消费者规则；其公网服务、响应边界、缓存和地区失败降级理由仍有效。[菜单栏显示设置](2026-10-22-menu-bar-preferences.md)继续拥有菜单栏的显示与持久化规则。

## Alternatives considered

- 仅隐藏总览视图：仍会保留无消费者的历史数据与每秒采样回调，增加维护和运行开销。
- 地址检查继续借用菜单栏速率采样：仅图标模式下将失去自动地址更新，或需要继续进行无消费者的速率采样。

## Consequences

主面板不再提供整机速率历史。地址轮询具有独立的启动、停止和重开测试，公网缓存及迟到响应测试继续保留；真实菜单栏脚本验证仅图标模式下地址与应用采样仍正常。浅深色离屏预览检查移除后的布局。未扩大公网服务或缓存策略，也未改变菜单栏样式。
