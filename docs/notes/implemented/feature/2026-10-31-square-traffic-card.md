# Agent Note: Square traffic card

Status: implemented

## Problem

列表按面板剩余高度伸缩，即使隐藏底部半行，也会留下固定的白色余量。用户要求应用网速列表卡片为正方形，底部与完整行贴合。

## Decision

固定列表卡片宽高相等，以表头和十条原有高度的记录填满卡片。适当增加整个面板高度，并为多地址预留固定空间，避免查询结果变化挤压列表。加载、空列表、错误和短列表保持同一尺寸，避免采样刷新造成窗口跳动。

此决定取代[紧凑面板](2026-10-31-compact-panel.md)中列表随剩余高度伸缩的布局；保留其字体、紧凑列宽、隐藏滚动条和底部完整行规则。当前尺寸由[界面设计说明](../../../interface-design.md#视觉标记)维护。

## Alternatives considered

- 只将列表高度向下取整：可以减少底部余量，但宽高不相等，且多地址时比例改变。
- 保持原面板高度并缩窄列表：列表会比其他卡片窄，进一步压缩应用名称与速率空间。
- 按记录数量收缩卡片：短列表不再是正方形，刷新时也可能改变面板布局。

## Consequences

列表起点和终点不再有固定的底部余量；保留原生连续滚动，停在非整行位置时，隐藏底部半行仍会形成少量空白。记录少于十条时保留空余区域，以维持正方形。单个本机地址时，网络卡片保留多地址所需的额外空间；整体窗口比原来略高。

真实视图离屏预览覆盖浅深色、起点、半行偏移、末尾、短列表、多地址及加载／错误状态；不能替代真实触控板手感和桌面材质检查。
