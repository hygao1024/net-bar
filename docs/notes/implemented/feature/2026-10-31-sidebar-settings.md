# Agent Note: Sidebar settings

Status: implemented

## Problem

用户希望设置界面参考 macOS 系统设置的侧栏导航、彩色图标、固定页标题和浅灰分组布局。原有顶部工具栏和紧凑窗口不符合这一视觉方向。

## Decision

使用原生侧栏列表选择菜单栏与软件更新页面，侧栏以彩色圆角图标区分页面，活动窗口选中项使用蓝色强调。右侧只显示当前页标题，去掉重复的 NetBar 品牌标题与大图标，设置正文独立滚动；版本号位于侧栏底部。分组采用低对比底色、细描边和紧凑设置行，延续系统设置的信息密度。只呈现现有两个页面，不为模仿参考图增加空分类、搜索框或没有导航历史的前进／后退按钮。预览与显示模式合并为一张卡片，让调整项和结果相邻。

设置控制器拥有页面选择状态和字体面板目标，侧栏绑定到同一状态；切页前关闭字体面板并清空目标。窗口关闭仍由 AppDelegate 统一清理，更新会话仍归应用级 UpdateController。旧偏好存储、更新操作和字号约束不变。

此决定部分取代[紧凑原生设置](2026-10-23-compact-settings.md)的工具栏导航与窗口尺寸；原有字体面板和更新生命周期决定保留。当前视觉尺寸由[界面设计说明](../../../interface-design.md#菜单栏设置)维护。

## Alternatives considered

- 只调整卡片颜色：保留旧导航结构，无法满足参考图的布局方向。
- 自绘侧栏按钮与键盘选择：需要额外维护选择、焦点和辅助功能行为；原生列表已拥有这些能力。
- 增加更多分类：当前只有两页设置，额外分类没有实际内容。

## Consequences

窗口比旧版宽，以换取固定导航与舒展的设置行；不改变菜单栏弹出面板的尺寸。只提供关闭按钮，避免将临时设置窗口最小化到 Dock。内容较长时滚动，切页回到顶部。

真实窗口预览覆盖浅深色、三种显示模式、字体回退及更新状态；原生侧栏选择与字体面板清理由菜单栏检查验证。离屏预览中的系统控件可能呈非活动灰色，不等于真实窗口禁用。其他 macOS 版本和完整读屏操作仍需人工验证。
