# Agent Note: NetBar naming and application identity

Status: implemented

## Problem

项目从 NetSpeed 更名为 NetBar，需要统一消费者可见名称与开发入口，同时避免因品牌更名使已保存的菜单栏设置失去归属。

## Decision

应用展示名、可执行文件、Swift 包及模块、源码和测试目录、构建产物与相关提示统一使用 NetBar。应用与菜单栏图标继续使用原有绘制路径和配色，仅更新无障碍名称。

保留 Bundle ID（应用唯一标识）`com.hygao1024.net-speed`。打包应用使用标准 UserDefaults（用户偏好存储），保留标识可以继续读取原有设置，无须引入跨存储域迁移。仓库目录及远端地址不属于应用品牌表面，本次不改动。

## Alternatives considered

- 同时更换应用唯一标识：会创建新的偏好存储域，并改变系统登录项身份；品牌更名不需要这些变化，因此保留原标识。
- 只修改应用展示名：构建产物、开发命令与源码模块仍使用旧名，无法完成项目统一更名。

## Consequences

旧标识是兼容契约，不作为遗漏的品牌名称清理。新旧打包应用共享偏好存储，不应作为两个独立产品并行使用；安装与登录项处理见 README 的升级说明。保留标识不保证系统会自动修复已注册登录项的旧路径。

验证涵盖核心测试、真实菜单栏组合、界面预览、应用与磁盘映像构建以及新应用启动。实际注销登录后的自启仍需人工验证，自动检查不修改本机登录项。
