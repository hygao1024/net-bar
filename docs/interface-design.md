# 菜单栏界面设计

## 参考与取舍

以用户提供的 macOS 系统状态小组件截图为视觉参考：浅灰面板、偏白圆角分组、细描边、蓝色标题、紧凑的行间距、左侧标签与右侧数值。

内容聚焦应用网速，采用三个分组：采样状态、进程速率列表、底部操作。保留排序、空闲进程、交替行底色和关闭即停止采样。

```text
╭──────────────────────────────────────╮
│ 应用网速                             │
│ ● 6 个进程正在传输      共 32 个进程 │
╰──────────────────────────────────────╯
╭──────────────────────────────────────╮
│ 应用 / 进程          下载        上传 │
│ 图标 Chrome      2.50 MB/s  8.00 KB/s │
│ 图标 微信      842.00 KB/s  0.00 KB/s │
│             可滚动列表               │
╰──────────────────────────────────────╯
╭──────────────────────────────────────╮
│ 开机启动 ○                      退出 │
╰──────────────────────────────────────╯
```

名称左对齐，速率和表头右对齐。列表改为单行，完整进程名及 PID 放在悬停提示中，读屏仍会读出编号。表头吸顶，并与数据共享滚动区域，避免系统滚动条出现后列宽错位。

不增加总网速卡片或圆环：代理可能重复计数，进程总和不等于物理网卡速度，且网速没有可用于百分比圆环的固定上限。

## 视觉标记

实际采用动态系统颜色，以下为浅色模式参考色，不硬编码进控件：

| 用途 | 参考值 | 实现 |
| --- | --- | --- |
| 面板底色 | `#ECECEC` | `windowBackgroundColor` |
| 分组底色 | `#F8F8F8` | `textBackgroundColor` 以 65% 不透明度叠加 |
| 细描边 | `#DEDEDE` | `separatorColor` |
| 主要文字 | `#1D1D1F` | `primary` |
| 次要文字 | `#6E6E73` | `secondary` |
| 重点文字 | `#007AFF` | `systemBlue` |

使用系统字体 SF（San Francisco）及中文回退字体。标题 13 pt 中等字重，名称与数值 12 pt 常规字重，单位 10 pt，底部说明 11 pt。数值采用等宽数字，避免刷新时横向跳动。

面板 380 × 440 pt，外边距 8 pt，分组间距 6 pt，组内横向边距 10 pt，圆角 8 pt，描边 1 pt。列表行高 26 pt，图标 16 pt。相较上一版缩小约 20% 的面积，保留原字号以保证可读性。外层圆角、箭头和阴影由 NSPopover 提供。

## 可访问性与验证

应用图标采用蓝色渐变圆角底板与两条错位的白色流线，沿用已确认的简洁方案。`Sources/NetSpeed/BrandIcon.swift` 保存共享矢量路径；状态栏使用 18 × 18 pt 的 `NSImage` 模板图像，透明背景，由系统根据菜单栏外观和选中状态着色，小尺寸下略加宽笔画以保持清晰。图标不随网速刷新。

`scripts/build-app.sh` 自动生成标准 16–512 pt（包含 2× 分辨率）的应用图标，转换为 `AppIcon.icns` 并打包进应用；`CFBundleIconFile` 指向该资源。构建同时在 `.build/status-icon-preview.png` 输出黑白轮廓的放大及 18 pt 实际尺寸预览。

当前排序列采用蓝色和中等字重，读屏提供选中状态及升降序；表头不添加箭头，底部左侧放置原生迷你“开机启动”开关，右侧保留“退出”按钮；需要系统批准时才在开关旁显示“待批准”入口。状态圆点同时配文字，不只依赖颜色。退出支持 ⌘Q，错误提供重新采样按钮。保留浅色和深色适配，不添加装饰动画。

界面参考 Apple [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) 和 [Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)；不代表 App Store 审核结论。

执行 `bash scripts/render-previews.sh` 可在 `.build/ui-previews/` 生成真实 SwiftUI 视图的离屏预览，包括浅色、深色、短列表、滚动列表、加载、空列表、错误状态及开机启动开启／待批准状态。预览使用示例速率，不采样网络，也不修改系统外观。
